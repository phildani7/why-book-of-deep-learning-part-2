# The Why Book of Deep Learning, Part 2: the notebooks

The runnable labs for *The Why Book of Deep Learning, Part 2* by Dr. Philemon Paul Daniel: one per chapter, 33 to 63. Every notebook
was run from top to bottom in a fresh kernel and saved with its outputs, so you can read the results before you run anything.

* **Read the book free:** [www.micyaai.com/books/why-deep-learning-2/](https://www.micyaai.com/books/why-deep-learning-2/)
* **Part 1 (Chapters 1 to 32):** [github.com/phildani7/why-book-of-deep-learning-part-1](https://github.com/phildani7/why-book-of-deep-learning-part-1)

Click a badge to open a notebook in Google Colab (free, nothing to install), then *Runtime > Run all*.
Tested with TensorFlow 2.21 and Keras 3.14. Each runs on a laptop CPU in about five minutes or less, with
NumPy, Matplotlib and TensorFlow/Keras only and no downloads beyond the built-in Keras datasets (Chapter 56
also uses scikit-learn if it is installed). Colab's free CPU runtime is enough; a GPU runtime also works.
